# Mortal rules 0.2.0 — implementation contract

This new authority resides under packages/ledger/src/mortal. It never writes to gameplay-v1 or character-memory-v1 storage. New genesis only, signed history bound to the complete immutable genesis hash. No import of human referee records, Fate role, life-year currency, anomaly, consent substitute, magic or character-memory carrier exists in this profile. An actor's health is derived from HP: positive standing, zero unconscious, negative dead. A dead actor cannot act or be restored by rest. No second alive/thread flag exists. Fresh-world identity and authenticated principal delivery are host responsibilities; never run this and v1 as two writers for one world/branch.

## Frozen API

Types in packages/contracts/src/mortal-types.ts are the shared shape. New schemas live at SYSTEMS/mortal-v2/mortal.schema.json. contracts/src/mortal.ts exports assertMortalContract<K extends keyof MortalContractMap>(name:K,value:unknown):asserts value is MortalContractMap[K], assertMortalGenesis(value:unknown):asserts value is MortalGenesis and mortalSchema. Public contracts entry exports those and all mortal types/constants.

ledger/src/mortal/rules.ts exports initialMortalState(genesis):MortalState; resolveMortal(genesis,state,command,principal):MortalResolution; mortalStateHash(state):string; mortalCapacity(state,actorId):{used:number,limit:number}. resolveMortal is pure, performs full state-dependent admission, never mutates inputs, and returns a state with sequence incremented but head still equal to the input head. mortalStateHash excludes ONLY head, eliminating event-hash circularity; all other state fields are included. The store sets head to the accepted event hash. No idempotency map grows in state; storage owns indexed request deduplication.

ledger/src/mortal/journal.ts exports createMortalEvent(genesis,state,command,principal,privateKey):{event,state,receipt}; replayMortal(genesis,events):MortalState; verifyMortalEvent(genesis,state,event):MortalState. Engine-derived consecutive draws/effects and before/after state hashes must match on verification. Signature covers every event field except signature and hash; event hash covers everything except hash. Genesis hash is initial head and previous_hash of event1. Receipt request_hash binds {command,principal}; complete scope/version/identity travels with every event and receipt. Host-only functions and histories contain private information.

ledger/src/mortal/storage.ts exports async openMortalLedger({path,genesis,privateKey,expectedHead?}):Promise<MortalLedger> with async snapshot(), events(), submit(command,principal), close(). privateKey is node crypto KeyObject; expectedHead is MortalCursor, an optional external trusted checkpoint verified as a prefix at open. File storage uses worker-owned node:sqlite WAL and BEGIN IMMEDIATE, with atomic event/index commit; no host event-loop blocking, stale lock files or external callbacks within transactions. A handle verifies history once, then verifies only new events. The state cache is derived; external rollback requires an external checkpoint, not a self-authored claim. Snapshot/events accessors are host-only. Caller/OS/database trust and resource bounds must be documented.

## Shape and semantic limits

All DTOs are passive plain data: refuse proxies before traps, accessors, exotics, symbols, hidden properties, sparse/decorated arrays, cycles, unsafe/noninteger/-0 numbers; bounded depth32/visits100000. IDs use the v1 safe ASCII alphabet with exact lengths and reject prototype keys. Closed objects and bounded arrays. Scope includes exact rights namespace identity. At most64 actors,512 items,128 locations,256 routes/opportunities/stocks; commands have at most12 participants per side and24 total. Initial world_time and actor activity clocks are0, no discoveries, fed_until0,next_rest_at0; initial HP positive and <=max<=100; ability bonuses0..10. Values/resources/clocks bounded safe integers (resource<=1e6, clocks<=1e12); commands buy/give at most100 units, wait at most24 turns. max1000000 events. Keys must be public-only Ed25519 PEM; seed64 lowerhex, pack_hash64lowerhex. Scope/key/seed immutable. World actor IDs, item IDs and location IDs unique in each collection; actor/item IDs disjoint. Referee principal ID is a separate identity, not an actor. All references resolve; item placement exactly one holder or ground location; held items use location_id:null, grounded use owner_id:null and equipped:false. At most one equipped weapon and one armor per actor. Nonweapon damage0/attack_ability:null; weapon damage4/6/8 and strength(melee) or wisdom(ranged); armor alone has armor_defense12..16, others0; tool alone may have lamp/firekit tag, all others tool:null. Route endpoints differ and exist, turns1..144. Opportunities are finite, turns1..24, target0..30, reward_units1..10, remaining0..100; stock resource cannot be obols, price1..1000, finite remaining/treasury. Every actor's initial carried capacity must fit.

## Admission and time

No caller selects dice, HP outcomes, time, arbitrary patches or privileged witnesses. Full scope/version, direct actor authentication (principal_id equals actor.controller_id, role equals actor.kind, actor_id matches), expected sequence/head and causation_id (null or current head) are checked before resolving. Referee-only begin_encounter requires principal role referee, principal_id genesis.referee_id, null actor IDs; a trusted host establishes the visible situation, never an NPC/model. Referee cannot impersonate player attacks. Initial state valid, state genesis_hash matches; state arrays remain detached.

One active encounter per world; out-of-combat actions are refused until it ends, preventing asynchronous time skips through a battle. Outside encounters, only the acting traveler changes location or spends supplies. Global world_time advances by that action's duration. Active expedition time is tracked separately on each actor: absent/nonparticipating actors do not spend food or rest allowance when someone else advances the world. This is an explicit v0.2 scheduling adaptation, not simulated all-world metabolism. A combat round advances global time and each non-escaped participant's active time by6 seconds once. Food/water is prepaid per active24h period: whenever positive active time advances past fed_until, spend one ration and one water if available and extend fed_until by86400; each missing unit instead causes independent d4 damage. No clock increment from reads/wall time. On death an already admitted travel action finishes at its declared destination; future actions refuse.

Capacity: item slots + rations + water + ceil(oil/18) + ceil(obols/100) + ceil(ammo/20); max Constitution+10. Consumable containers are abstracted in v0.2 (empty containers do not persist as extra slots). No second spendable resource stacks. All capacity-increasing actions refuse if recipient would exceed limit; travel, combat entry and retreat require capacity fit. Currency is conserved between actors/stock treasury; purchases never mint stock. Resource transfers require positive bounded quantities and same location, standing giver and living recipient. A depleted item is not recreated by a scene reset.

## Exploration, ownership and recovery

Travel uses an actual undirected route from actor location, charges turns*600 seconds. If requires_light, require held lamp+firekit and enough oil; burn one oil unit per exploration turn. Route hazard, if present, is announced host configuration: one d20+ability >target, failure its declared damage die. No NPC or prose grants a new route.

Explore uses co-located configured opportunity, remaining>0, optional light, turns*600 time. One strict d20+ability >target; success consumes one remaining unit and grants configured reward. A search is once per actor (record opportunity ID in discoveries on every attempted search, so failure cannot reroll unchanged circumstances); foraging can repeat at its fixed time/cost until finite stock ends. Refuse a possible reward that would exceed capacity before draws. Failure may deal declared die damage. Refused action consumes nothing; an admitted failed roll spends time/light and can incur supply costs. Discovery IDs are private actor data, not automatic party knowledge.

Wait spends turns*600 active/world seconds; no recovery. Rest requires HP>=0, location.safe_rest, no encounter and active_seconds>=next_rest_at. It lasts28800 seconds, requires food/water coverage for that period (no starvation rest), heals d8+Con capped maxHP, and sets next_rest_at to rest-start active_seconds+86400. No resurrection, repeat-nap farming or other actor's elapsed time resets this allowance.

Equip own item while standing and out of encounter; at most one weapon/armor equipped. Transfer own item to co-located living actor or ground; equip flag clears. Pickup grounded local item, loot only local dead owner's item; ownership and capacity are authoritative. Give resources and buy finite configured local stock; no trade during encounters. Purchase deducts units*price obols, increments that stock's treasury, decrements stock remaining and credits resource; post-transaction capacity checked.

## Combat

Host begin_encounter admits unique standing co-located participants, nonempty sides, bounded roster and a declared escape_allowed flag. Both sides must include at least one player or NPC; Fates are not present in this profile. Roll one d6:1..3 side_a first,4..6 side_b first; preserve declared order inside sides. Each standing non-escaped actor gets one action per round. At turn start expire that actor's defend bonus; defend grants+2 armor until its next turn. Attack requires equipped owned weapon, opposing active standing target in the same encounter/location. All admitted participants are within this small encounter's weapon range; there is no tactical grid or invented distant shot. Attack d20+strength/wisdom >target armor (equipped armor or11) + current defend bonus; ties miss. Ranged consumes one ammo even on miss. Hit deals one weapon damage die. HP0 unconscious and excluded from turns; negative dead. No automatic criticals. pass spends the turn. retreat uses the action, requires declared escape and capacity fit, removes only that actor from encounter without opportunity attack, and keeps its site location (reaching nearby shelter, not teleporting along a route). A new pursuit requires a separately admitted host encounter; there is no free automatic retaliation. Encounter ends once either side lacks standing non-escaped members; defeated actors retain possessions. Do not award loot, refill supplies, grant experience, heal or move anyone upon ending. Advance finite turn/round without recursive empty turns; same request retry is not another turn. NPC actions are submitted through their authenticated controller, not privileged arbitrary rolls. Morale/tactical-grid/stunts remain later explicit actions, never prose state patches.

## RNG and isolation

Use HMAC-SHA256 keyed by genesis.seed, with counter and fixed internal purpose (no request_id/caller label) and rejection sampling for fair 1..sides. Consecutive records {index,purpose,sides,value}; local copy counter means all refusal leaves RNG/state untouched. Replay recomputes every draw and transition. Parent/read accessors never expose this seed or host history to players. Actor view is separately scoped to directly authenticated viewer; includes only self resources/discoveries/items and permitted encounter facts, never other actors' private stores or hidden rolls. Character/narrator-v1 adaptation and production identity/perception remain distinct future integrations.
