# Shared-world privacy/model/host acceptance plan

Baseline: frozen `shared-world/0.1.0` at `8ff20160fcd949a64e5e11c356d5de57d769983e`; reviewed contract source `186e052a19de6466aedaf048ecb5d9c4fd4fc1eb`. This is a plan, not a runtime verdict. Wait for immutable SW-400/SW-500 candidates; record exact SHA, clean status, relevant file hashes and freeze equality before/after. No repository edits, paid calls, nested agents or automatic model launch.

SW-400/SW-500 source checks can use injected scoped views and clients. Witness acquisition, current-prefix host enforcement and receipt binding require the integrated SW-200/300/510 runtime; mock views alone do not prove those boundaries.

## Acceptance matrix

| Boundary | Independent probe and required outcome |
| --- | --- |
| Witness acquisition | Real authority speech from A with B present, C remote, D unconscious and E arriving later. Self-private reaches A only; whisper reaches exact standing colocated addressees; room speech reaches standing occupants. Remote/unknown/nonstanding explicit addressees reject atomically. C/E never acquire earlier records through party membership or arrival. Source always matches authenticated actor. |
| Addressed versus overheard | An NPC may respond to acquired speech explicitly addressed to it, never merely overheard speech, self speech or missing evidence. Repeat same inbound after32+ intervening records: full-history duplicate rejection still holds. Different NPCs can each answer their own addressed inbound once. Model/context code has no ledger writer. |
| Own policy and opinions | Capture the actual injected provider request. Melia receives her immutable nature, private presentation, relevant own impression and exact selected authored loan policy. Another NPC gets none of these by campaign/room membership. Player opinions do not become room facts or shared reputation. Hidden seed/variant/controller/grant roster/raw events/rolls/private inventories never enter the request. |
| Shared definitions | One current room description/name/environment per context, sourced from immutable genesis and actual current location. Altered pack/source bytes, forged pins and duplicate/generated-ID collisions fail. No stale seed occupancy supplies present actors. Definitions appear once; incoming record is not repeated in history; opinion/source/provenance labels remain distinct. |
| Model wire and output | Use real reusable request construction with injected transport and capture bytes. Explicit small output limit remains small for Google; no tools/history/continuation/live-default client; full rights/world/branch/actor/profile-scoped cache identity. Reject extra JSON fields, tool/authority payloads, oversized/malformed/incomplete/refused output. Text/null only; no template fallback, paid retry, LLM repair or code-driven acceptance of a bargain. |
| Exact-current refresh | Barrier callbacks at initial read, async token count and delayed generation. During each, change cursor/head/time, move actor, change activity/standing, revoke knowledge, consume inbound or close mythic engagement. Before-generation changes prevent provider dispatch; during-generation changes suppress output. Replay an old pre-revocation/pre-closure query: session/model refresh must refuse it rather than serving a historical view. Cancellation/deadline suppress late output without another attempt. |
| Receipt response binding | Through public session API, inject a genuinely signed valid receipt from a different request on the same world/key. Reject despite valid signature. Bind full request domain hash, command, fixed authenticated principal, request ID, scope, genesis and expected event progression. Correct exact retry may return its older original receipt; changed command/principal reuse must fail. Receipt contains no effects/raw event/state. |
| Third-holder loan privacy | A lends privately to B; C later receives/finds item and returns to A. C receives only `custody_returned` item/from/to; no loan/offer/original-borrower identity. A and present B retain appropriate loan memory; absent B and room bystanders receive no remote/private update. Ordinary transfer/pickup/loot fulfillment uses the restrictive compound record. |
| Exact campaign/kit | Compare genesis/manifest with pinned pack, catalog and source hashes. Only ordinary mortal roster, one controller namespace, exact private profiles and shared scenes; no Fates/loom/lifespan authority. Standard kit and borrowed-lamp kit differ only as documented; borrowed-lamp removes the player's personal lamp, preserves Melia's `traveler_lamp`, and uses collision-safe actor IDs. Explicit day/night behavior is preserved; source pack and old factories remain byte-identical. |
| Full integration | Public APIs: fresh night/borrowed-lamp world → ask Melia → injected contextual reply → structured offer → exact explicit acceptance → one atomic promise/custody event → travel/oil → return → restart/replay. Refusal/stale race/capacity failure leaves no partial obligation or custody change. Run CLI as an ordinary process with `NODE_TEST_CONTEXT` absent as well as named tests. |

Exact authored policy assertions: zero fee/deposit; replacement and actual-agreed repair cap5 obols; borrower supplies oil priced1 obol for6 exploration turns; explicit return agreement, normally next harbor return; no compulsory service/oath. Authored terms remain an offer policy until a separate structured authority transaction accepts them. Do not silently substitute a different mechanical unit interpretation into the quoted policy.

Fixed source identities: pack `70adb204c3f5626957d69ff5c0107b4c2954714390f1e5cb37a97de61fea5161`; catalog `da7f45ff9a8d6874c98d4eba4e0c7e658c0259d139f032bf6e146f1872ebb2a0`; source manifest `c6ec5f0c7a8824d83939028a5660df8e8c24202bd6029660f150ef9b3de0391f`.
