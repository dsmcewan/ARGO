# Runtime knowledge review preparation

Scope: the additive authored actor knowledge runtime and its integration with the existing NPC model adapter. Final review waits for a coordinator-supplied immutable integrated candidate.

The portable probe will use the package public entry points and injected provider responses. It checks exact Melia loan terms and honest source attribution, independent content pins, owner/scope/cursor/acquisition isolation, malformed/missing grants, source-byte validation, passive input limits, old dialogue 0.1 compatibility, model-request exclusions, cache version separation, and grant revocation during counting/generation. It will not write authoritative world state or call a paid provider.

The review distinguishes shape and hash-binding checks from authenticated host knowledge. JSON cannot prove that a host persisted an activation, authenticated an issuer, or verified an earlier cursor's ancestry. A generic valid supplement is not a signature or content attestation; the fixed campaign builder and trusted host binding must establish the selected policies.

Run after the coordinator freezes the integration:

```sh
node runtime-probes.mjs /absolute/path/to/ARGO <immutable-commit-sha> /absolute/path/to/output-directory
```

The probe requires a clean candidate and installed locked workspace dependencies. It records exact public module paths and source hashes. Findings are provisional until reproduced at the supplied commit. No final verdict is made by this preparation document.
