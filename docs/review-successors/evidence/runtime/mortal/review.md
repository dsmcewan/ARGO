## Strengths and concrete checks

1. **Encounter exclusion closes indirect resource paths.** `packages/ledger/src/mortal-v3/rules.ts:113` blocks ordinary activity by the complete original roster and all actors at the fixed site, plus remote entry and roster transfers. Existing local ownership/co-location checks cover stock, opportunities, ground items and corpse recovery. Independent probes exercise remote legitimate activity, local bystanders, escaped roster members, dead roster owners, protected ground items and cross-site transfer attempts. Closure releases these locks without moving actors or awarding loot.
2. **Recovery is bound to the actual waiting turn.** `rules.ts:96` checks the exact configured referee identity, role, null actor identity and scope; `rules.ts:104` binds encounter identity and turn token in addition to the ordinary expected cursor. `rules.ts:210` updates the token only on a genuine logical turn transition. Remote commands leave it intact; fresh-cursor commands cannot revive an old token or reuse one after a later encounter with the same ID.
3. **Time and needs settle consistently.** `rules.ts:196` and `rules.ts:268` use the existing needs engine. Pass is the same turn/round transition as voluntary pass; close pays the pending round exactly once, including both simultaneous hunger and thirst rolls even if the first kills. Independent tests cover immediate close despite escape prohibition, retreat followed by starvation, the escaped actor's original-round charge and exclusion from later rounds, next-round close, no extra RNG with supplied actors, and no refunds/healing/loot.
4. **Concurrency retains one writer outcome and exact retries.** `storage-worker.ts:65` publishes cache state only after transaction commit; `storage-worker.ts:129` reads the authenticated request index before new action admission. Two handles concurrently submitting an identical close produce one event and identical receipts. Normal pass versus recovery with one expected cursor produces one winner and one conflict, and total eventual cost remains six seconds. Restart, replay equality and exact historical retry preserve the outcome.
5. **Journal and disclosure remain separated.** `journal.ts:45` signs command, principal, draws, effects and state hashes; `journal.ts:69` re-runs deterministic rules on replay. Actor disclosure at `view.ts:13` explains only that viewer's roster/site lock, hides encounter details from remote and escaped viewers, and does not include controller, seed, referee reason, token or another actor's inventory/resources. Public exports remain explicit at `packages/ledger/src/index.ts:180`; `scenarios/tempted-fates/runtime-v3.ts:9` creates a distinct fresh genesis without opening a database or changing v2 initialization.
6. **Version separation and trust limits are honest.** `storage-worker.ts:80` refuses v2/mixed tables and mismatched existing genesis before WAL/schema mutation. Independent probes verify both mixing directions preserve committed database bytes. The README correctly calls shared RNG a serialized stream, world time a serialized duration sum, `expectedHead` an external ancestor checkpoint, and the live incremental cache dependent on already verified rows remaining append-only.
