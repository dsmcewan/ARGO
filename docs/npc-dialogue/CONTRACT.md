# NPC model adapter: character-dialogue/0.1.0

This is an additive presentation interface, not a new ledger profile. It composes the existing character agent, scoped character reader and shared model client. Existing character commands, witness decisions, signatures and replay rules remain unchanged. This interface is fixed before implementation lanes begin.

`createModelCharacterAgent(options)` is exported by `@argo/interventions`. Options are `{scope, actorId, sessionId, candidates, clientFor, refreshContext, countTokensFor?, readSupplement?, timeoutMs?, maxContextBytes?, maxOutputTokens?, effort?, cooldown?}`. `refreshContext(query,{signal})` returns a current authorized `CharacterView`; optional `readSupplement(query,{signal})` returns `DialogueSupplement | null`. These loaders are host capabilities bound to an authenticated actor, not authentication services themselves. `clientFor` supplies existing SDK clients; `countTokensFor(candidate)` can supply a trustworthy counter when the SDK does not expose one. No credentials, SDK construction or network calls occur at import/factory creation.

Methods are `respond(query,recordId,requestId,{signal?,communicationGoal?}?)` and `impress(query,subjectActorId,evidenceIds,requestId,{signal?}?)`. They return `Promise<CharacterCommand|null>`. They never submit commands. The existing authenticated character bridge remains the only commit path. Deterministic activity/alive/address/cooldown/cutoff checks precede model generation. Optional communicationGoal is bounded turn-level data (maximum 512 Unicode characters), not an instruction overriding character agency or authority.

The optional supplement has exactly `{version:'character-dialogue/0.1.0',query,source:{content_hash,revision},actor,scene}`. `actor` is null or exactly `{actor_id,name,occupation,wants,will_not}` and must belong to the queried actor. `scene` is null or exactly `{location_id,name,description}`. The content hash is lowercase SHA-256; revision is a bounded nonempty string. Actor/room identifiers use existing actor identifier grammar. Names are at most 256 Unicode characters; occupation 512; wants/will_not 2048; scene description 8192. Unknown keys, active/proxy/accessor objects, cycles and malformed arrays are refused. The supplement query must equal the complete reader query, including cursor and scope.

Scene fields are explicitly disclosed authored facts from one content revision. Actor goals are private disposition. Neither character agreement nor claim text can enter the scene fields through this API. The host adjudicates which authored room may be seen at a given cursor; seed occupancy is not evidence of live presence. No mortal state, full campaign pack, referee notes, private_knowledge, variant truth or narrator archive is accepted as model context. Static scene projection does not implement dynamic weather or connect distinct authority profiles.

The prompt defines current/historical nature revisions once, includes the exact acquired experiences once, and identifies the incoming/evidence records by ID. It selects the interlocutor/subject's latest private impression, preserving provenance and prior nature revision. Omission counts describe this selection. Conflicting nature values under one actor/revision are refused. The current reader's 16-experience limit remains; older promises require a future retrieval contract.

Each speech or impression task makes one generation call in the successful case: empty history, replay continuity, low effort by default, scope/actor/task-separated cache keys and no tools or exposed streaming. Route at most one attempt per candidate pool, with a single end-to-end deadline including counting, refresh and optional cooldown I/O. Defaults: 10,000 ms (range 1..60,000), 32,768 input UTF-8 bytes (range 1,024..131,072), and 2,048 combined output/reasoning tokens (range 1..8,192). The model client gains `outputBudgetPolicy:'explicit'` so Google honors an explicit small cap; its omitted/default policy retains existing long-decode behavior. No live provider capability claim is added.

The model returns JSON with exactly `{text:string|null}`. Null means silence/no new impression. Nonempty text is limited to the character's existing Unicode speech budget, or 2048 characters for impressions. Reject incomplete/refusal/tool responses, malformed/extra-key JSON and response bodies exceeding 32,768 UTF-8 bytes. A stable behavioral instruction asks the model to understand the addressed message, weigh the character's knowledge/traits/goals, decide what to communicate or withhold and express it naturally. It provides no canned dialogue lines and asks for no exposed reasoning trace. Prompt content is untrusted data, not authority.

Refresh and compare the full authorized view and selected supplement before every provider attempt and after generation. If they change, become unavailable or cross the cutoff, suppress the proposed command. Caller cancellation propagates. Freshness at commit remains the existing expected-cursor check. Scope/version checks establish shape and binding, not proof that an untrusted host told the truth.

`buildCampaignDialogueSupplement(pack,query,{location_id:string|null})` is exported by `@argo/tempted-fates`. It validates the pack/query and projects only the queried NPC's name/occupation/wants/will_not plus the explicitly granted room's name/public_description. Null location discloses no room. Unknown room IDs fail. Travelers get actor:null. The helper accepts no seed occupancy inference, private knowledge, sample speech, route catalog or referee truth. The caller must wrap it in an authenticated current-cursor disclosure loader.
